# Dr.core Recovery LP

器具に身体を支えてもらいながら行う「自重ストレッチ」を紹介する、Dr.core RecoveryのLPです。平日昼の予約につながるよう、ラクに伸ばせることと日常のすき間に通えることを伝え、トップ・月島店・本八幡店の3ページを共通テンプレートから生成しています。通常プランは1回30分、初回体験は60分・体組成／姿勢診断付き・1,000円です。既存の大人向けLPのロゴ・写真を使用し、ReViNaとDr.stretchを参考に、白を基調としたわかりやすい構成にしています。ブランドカラーのグリーンとレモンイエローを活かし、ゴールドは主に体験予約の導線に使用しています。

都度払いの価格と服装・設備の条件は未確定です。2026年10月30日の本番反映依頼に合わせ、公開画面では内部確認用の表示を除き、店舗への問い合わせをご案内します。価格を推測したり、手ぶら・普段着・着替え不要・シャワー利用可と断定したりしていません。条件が確定したら、データとFAQの問い合わせ案内を正式な価格・条件へ更新します。

トップの5つのゴールドCTAは店舗選択 `#locations` へ移動します。店舗LPの5つのCTAは、それぞれの既存の大人向け体験予約URLを別タブで開きます。これは今回のユーザーの明示指示に合わせた導線です。予約URLと店舗名・住所・駅徒歩・写真の対応は `data/recovery-stores.json` にまとめ、既存 `build.py` の店舗データと照合しています。予約リンクには `target="_blank"` と `rel="noopener"` を設定しています。

ファーストビュー直下・初回体験の概要の末尾・料金の後・ページ末尾に、共通の四角い2段構成のゴールドCTAを配置しています。上段の価格枠には「初回60分」「10/31まで」「1,000円」、下段の予約ボタンには「初回体験予約」を表示し、ボタンの外側に「体組成・姿勢診断付き」の説明を添えています。画面下の追従CTAも同じ共通部品で、同じ情報を掲載します。体験の時間・診断内容・価格・キャンペーン期日・ボタン文言は `data/recovery-offer.json` から読み込み、`recovery_sections.py` で生成します。期日は2026年10月31日固定で、毎月の自動延長は行いません。初回体験60分・体組成／姿勢診断付きはユーザー指定に合わせた条件で、通常プランの1回30分とは分けて表示しています。追従CTAはファーストビューを通過すると表示されます。

3つのLPのヘッダーは初期表示では隠し、120px以上スクロールすると中央ロゴとメニューボタンを固定表示します。ページ上部に戻ると再び隠れます。ヘッダー用の空白は設けません。ファーストビューの左上には既存の白いDr.coreロゴ `logo-transparent.svg` を配置し、初期表示から見えるようにしています。表示幅はスマートフォン112px・PC124pxで、通常のヘッダーロゴ126px・142pxより少し小さくしています。店舗ページの店舗名・駅徒歩は白ロゴの下に配置します。スマートフォンのメインビジュアルは `100svh` で1画面を占め、左下にコピーを重ねています。3つの特徴と体験予約バナーはその後に続き、スクロールすると表示されます。

メインコピーは「自重ストレッチで／しなやかに動ける身体へ」の2行で、旧2行目の高さから始まります。本文の位置と各行の高さを保ち、長い2行目のみ文字サイズを調整して小さいスマートフォンでも1行に収めています。句読点は付けず、トップの「Dr.coreの自重ストレッチ」ラベルは削除しています。店舗ページの店舗名・駅徒歩は画像左上に維持しています。補足は「器具に支えられながら、自分では届かないところまで。30分のマンツーマン自重ストレッチ」です。ユーザー提供の縦長写真を、加工せず `dist/assets/recovery-hero-portrait.jpg`（1080×1920）に保存しています。スマートフォンではこの写真を1画面の背景にし、人物の顔と動作が見えるように配置し、下部のグラデーション上に白文字でコピーを重ねています。PCでは写真を右に、深いグリーンの背景とコピーを左に配置しています。極端に高さの低い画面では、可読性を優先して自然に縦へ伸ばせます。特徴はメインビジュアルの次の淡い背景に3つの円を横並びにし、完全予約制・マンツーマン、30分の通いやすさ、平日10〜15時の1回4,750円〜を表示します。最低単価には「平日デイタイムプラン・月8回の場合」の条件を添えています。3つのLPのOG画像も同じ提供写真です。ヘッダー・フッターのロゴ横、本文、FAQのサービス名は「自重ストレッチ」に統一しています。

お悩みは「最近こんなお悩みはありませんか？」の見出しと、肩・腰の重さ、つまずき、姿勢、身体の硬さ、スポーツの動きの5カードです。濃いグレーの背景とカードに明るい文字・独自の線画SVGを組み合わせ、参考画像のアイコンは転用していません。PCは上段3枚・下段2枚、スマートフォンは2枚ずつと中央の1枚で配置し、本文は16px以上を保っています。スマートフォンの見出しは「最近こんな」「お悩みはありませんか？」の2行です。5つのカードの後は、説明ブロックを挟まずに平日昼のセクションへ続きます。「平日昼の30分を、自分のために。」は、お悩みセクションの外にある独立した `#daytime` です。クリーム色と空色の背景を画面の左右端まで広げ、周囲や下にグレーの背景が残らない構成にしています。「在宅ワークの昼休みに」「平日休みの日に」「家事の合間に30分」の利用シーンと陽だまりのモチーフを維持しています。平日デイタイムプランへの導線は高さ60px以上の大きなボタンです。

お悩み・3つの強み・通常セッションの説明・初回体験の概要・体験の流れ・FAQは、お客様の声に合わせて見出し・写真・余白をコンパクトに整えています。本文は16pxを基準に保ち、スマートフォンでも読みやすいカード幅にしています。3つの強みの各タイトルはPC20px・スマートフォン18pxとし、本文16pxより少し大きく表示しています。既存のトレーナー・店舗一覧・予約導線・小さくした追従CTAは維持しています。

「お客様の目的例」は削除し、お客様の声の次にトレーナー紹介を配置しています。フッターは黒背景にしています。

強みは「プロが導く、最適なストレッチ」「器具に身体を預けて、ラクに深く伸ばす」「伸ばすだけじゃない。動きやすい身体へ。」の3点です。見出しは「Dr.core 自重ストレッチ」「3つの強み」の2行で「｜」を使いません。器具の種類より、身体を支えてもらい無理なく伸ばせることを説明しています。強みの写真は、01が新たに提供されたポールを使ったストレッチ、02が新たに提供されたTRXでの側屈、03が以前02に掲載していたTRXストレッチです。写真枠はすべて4:3に統一し、従来の2.1:1より縦幅を確保しています。強みの直後にあったトレーニングへの案内は削除し、トレーニングは「ストレッチだけで通えますか？」のFAQ内で希望者向けの案内にとどめています。

通常セッションは `#session` で説明します。見出しは「30分で、全身を心地よく」「Dr.coreのアプローチ」の2行に固定しています。「可動域を広げる（モビリティ）」「器具に支えられた自重ストレッチ」「トレーナーが角度・強さを合わせるペアストレッチ」の3カードで、30分の内容を具体化しています。固定の分数配分は設けず、その日の身体の状態や希望に合わせて組み合わせます。通常30分と、体組成・姿勢診断を含む初回体験60分を明確に分けています。

初回体験の概要は「まずは一度、カラダの変化を感じてみませんか？」と「あなたに合ったストレッチを、初回体験で。」を配置しています。3項目は「今のカラダを一緒にチェック」「カラダに合わせて、無理なく伸ばす」「目標と生活に合う通い方をご案内」です。それぞれ、気になる悩みと姿勢・動かしやすさの確認、トレーナーのサポートによるストレッチ、目標と通える頻度に合うプランの提案を説明します。

初回体験の概要と後半の詳しい体験の流れは役割を分けています。後半は「体験予約 → ご来店 → 身体の状態確認 → ストレッチ体験 → 続け方をご案内」の5ステップで、各項目に番号・画像・タイトル・補足説明を配置します。スマートフォンは縦に読み進める構成です。FAQは身体の硬さ・体験・自重ストレッチだけの利用・通う頻度・時間別料金・入会の任意性・服装・着替え／シャワー・予約先の9問を、キーボード操作できる `details` / `summary` で実装しています。

体験の流れとFAQは、採用サイトではなくDr.core公式サービスサイトの構成と確認できた案内を基に自重ストレッチ向けへ調整しています。初回体験60分・体組成／姿勢診断付き・1,000円は、ユーザー指定を反映しています。「服装は？」「着替えやシャワーはありますか？」の2問には `data-store-inquiry` を付け、ご予約前に利用店舗へお問い合わせいただく公開用の回答を置いています。普段着の可否、レンタルウェアの有無・料金、両店舗の着替えスペースとシャワーは確認後に正式原稿へ差し替えます。

競合の口コミや効果保証は転載していません。既存大人向けLPの先着人数、キャンペーン期限、月会費の永続割引、ペア割引はRecoveryに適用していません。

## お客様の声の下書き

3つのLPのカードと共通の個別記事は `data/voices.json` から生成します。掲載順はAさん・Dさん・Cさんで、写真枠を含むカード全体のクリックから `/voices/a/`・`/voices/d/`・`/voices/c/` に移動できます。LPカードは写真枠、名前と年代、紹介タイトル、紹介文を掲載し、属性・テーマ・主な悩み・「詳しく読む」の文言を除いています。カードは小さめの横スクロール形式で、スワイプ・トラックパッド・左右ボタンに対応します。見出しは短く整理した2行で、`card_title` の改行位置をそのまま表示します。各記事の一覧へ戻るリンクは、共通トップの `/#voices` へ移動します。LPと3つの個別記事に「※個人の感想です。感じ方や変化には個人差があります。」を掲載しています。

現在は3件とも `is_sample: true` の掲載イメージで、実際の取材は行っていません。Aさんは平日昼の利用シーンに合わせ、カードと記事タイトルを在宅ワークの昼休みに変更し、記事にその利用場面を1段落追加しています。実際の取材内容として確定させず、`editorial_label` の「平日昼の利用イメージ（取材・写真確認待ち）」をカードに表示しています。Dさん・Cさんのカード原稿と詳細記事の本文は変更していません。3件の個別記事では従来のサンプル表示も維持しています。写真は未提供のため、LPカードと記事には中立的な「お客様写真 掲載予定」のプレースホルダーを表示します。`data/voices.json` の任意項目 `photo` にローカル画像のパスを設定すると、対応するカードと記事の写真枠へ反映されます。画像の説明は `photo_alt`、表示位置は `photo_object_position` で指定できます。

記事の本文は `paragraphs` に段落ごとに保存しています。Aさんは8段落、Dさんは9段落、Cさんは10段落です。生成処理は各段落を省略・要約・切り詰めず、段落内の改行も保持して全文を表示します。下書き記事には `noindex,follow` を設定し、サイトマップには含めていません。実際のお客様の声として掲載する際には、原稿・写真とサンプル表記を確認します。

## 料金の表示

金額・回数・入会金・他時間帯の加算額・都度払い価格は `data/recovery-plans.json` で管理し、`recovery_sections.py` が2つの月額料金表、都度払いカード、入会金の案内を生成します。月額プランの指定金額は1回あたりの料金で、月額は回数分を計算します。

税区分はRecoveryとして未確認のため、`tax_label` は `null` のままです。既存成人サービスの税込表記をRecoveryにも適用できるとは判断せず、税込・税別の表記を加えていません。

平日デイタイムプラン：平日10:00〜15:00にご利用の場合。既存の月額・1回あたり金額を維持しています。

| プラン | 1回あたり | 月額 |
| --- | ---: | ---: |
| 月1プラン（月1回） | 6,000円 | 6,000円 |
| 月2プラン（月2回） | 5,250円 | 10,500円 |
| 月4プラン（月4回） | 5,000円 | 20,000円 |
| 月8プラン（月8回） | 4,750円 | 38,000円 |

レギュラープラン：平日10:00〜15:00以外・土日祝にご利用の場合。デイタイムの1回あたり料金に1,000円を加え、月額には「回数 × 1,000円」を加算します。

| プラン | 1回あたり | 月額 |
| --- | ---: | ---: |
| 月1プラン（月1回） | 7,000円 | 7,000円 |
| 月2プラン（月2回） | 6,250円 | 12,500円 |
| 月4プラン（月4回） | 6,000円 | 24,000円 |
| 月8プラン（月8回） | 5,750円 | 46,000円 |

料金導入は「平日昼なら、1回4,750円〜」とし、「平日10:00〜15:00・月8回の場合」の条件を併記しています。「1回30分だから、気軽に通えて継続しやすい」の説明は維持しています。料金表の囲み枠をなくし、平日デイタイムプランを先に、レギュラープランを濃い緑で表示します。

自重ストレッチは入会金0円に変更し、当日入会の条件を外しています。旧入会金33,000円と「体験当日のご入会で0円」の表示は使用しません。月額制に加えて1回30分の都度払いカードを用意していますが、`pay_as_you_go.daytime_price` と `regular_price` はともに `null` です。月額プランの単価を都度払いへ流用せず、明示的な `unconfirmed_price_display: "contact_store"` 設定により「料金は店舗へお問い合わせください」と表示します。両時間帯は `data-price-inquiry` で識別し、数値を表示しないことを検証します。この設定がない未確定価格や内部確認用 `data-pending-content` は、引き続き公開用検証で拒否します。通常プランの30分と、体組成・姿勢診断を含む初回体験60分・1,000円は別に案内しています。

## トレーナーの素材

採用サイト「それぞれの想い」の公開HTMLで、氏名・写真・トレーナー表記を確認した高倉・吉岡・吉永・久保木の4名を掲載しています。紹介カードは写真と「名字＋トレーナー」のみで、経歴・資格・担当店舗を推測していません。

`data/trainers.json` に人物と写真の対応、画像サイズ、トリミング位置、取得元URL、SHA-256を記録しています。画像原データは `dist/assets/trainers/` に保存し、外部画像への直接参照に依存しません。詳しい確認記録は `data/trainers-sources.md` を参照してください。木嶋氏は別セクションの代表として掲載されており、今回の4名には含めていません。

- `dist/assets/recovery.js`：モバイルメニュー・追従CTA・体験案内クリックの記録
- `dist/assets/logo-dark.svg`：白背景用のDr.coreロゴ
- `dist/assets/concerns/`：お悩み5カード用の独自線画SVGと、以前の未使用イラスト素材
- `dist/assets/flow/`：体験の流れに使うイラスト
- `dist/assets/trainers/`：取得元を確認したトレーナー写真
- `recovery.py`：3つのLPとお客様の声の記事生成・アセットのキャッシュ更新・公開URL情報
- `build.py`：ビルドの入口。通常はRecoveryトップ・2店舗・3記事を一括生成
- `verify.py`：3つのLP・共通記事・予約URL・店舗情報・相対リンク・公開メタ情報の静的検証

プロジェクトのルートで実行します。Python標準ライブラリを使用するため、ビルド用の追加パッケージは不要です。未確定の原稿・価格を含む確認画面のローカル検証では、明示的に `--allow-pending-content` を指定します。

```sh
python3 build.py --origin https://drcore-recovery-lp.netlify.app
python3 verify.py --origin https://drcore-recovery-lp.netlify.app --allow-pending-content
node --check dist/assets/recovery.js
```

既存の `python3 build.py --full` もRecoveryのトップ・2店舗・3記事を生成します。生成済みの `dist/index.html`・`dist/gyms/*/index.html`・`dist/voices/*/index.html` は直接編集せず、テンプレート・店舗データ・原稿データを編集して再ビルドしてください。

公開用のビルドとメタ情報の確認は、確定した公開URLを指定し、`--allow-pending-content` を付けずに実行します。デフォルトの検証は、問い合わせ表示モードが指定されていない未確定の都度払い価格や `data-pending-content` が残っている場合に失敗します。問い合わせ表示モードでは、各時間帯の正しい問い合わせ案内と、数値が表示されていないことを検証します。

```sh
python3 build.py --origin https://drcore-recovery-lp.netlify.app
python3 verify.py --origin https://drcore-recovery-lp.netlify.app
```

3つのLPにそれぞれのcanonical・OG情報を設定し、サイトマップにはトップ・月島店・本八幡店の3URLのみを掲載します。下書きのお客様の声の記事は `noindex,follow` を維持し、サイトマップから除外します。`robots.txt` は `/gyms/` を含むLPのクロールを許可します。`--origin` を指定しないローカル用ビルドではcanonicalを付けず、サイトマップは空になります。

## 店舗ページと継続する確認事項

引き継いだ `dist/gyms/tsukishima/` と `dist/gyms/motoyawata/` はRecoveryの店舗LPへ更新しています。通常ビルドでトップと同時に生成し、各ページからほかの店舗とトップへ移動できます。成人LPを再生成する保守用オプションは `--legacy-adult` です。`--legacy-adult --full` は同じトップと店舗URLを成人ページで上書きするため、Recoveryの編集・公開には使用しません。

条件を推測して追加せず、次の項目を確認します。

- 都度払いの平日デイタイム／レギュラーそれぞれの料金
- 普段着での利用可否、レンタルウェアの有無・料金、各店舗の着替えスペース・シャワーの有無
- 税区分と実際の請求額
- 各店舗での受付可能な日時と、60分の初回体験の運用
- 自重ストレッチに適用する持ち物・支払い方法などの案内
- 将来Recovery専用の予約URLへ切り替える場合の各店舗のURLと運用
- お客様の声のサンプル原稿の掲載方針と掲載写真

`netlify.toml` はNetlify用のビルド・配信設定です。公開用ビルドで設定された `$URL` をoriginとして使用し、3つのLPと共通記事を生成・検証します。

本番公開は、内部確認用の文言・属性を外し、未確定条件を断定しない問い合わせ案内に整えたうえで、フラグなしの公開用検証に合格してから行います。確認用フラグで検証した成果物をそのまま公開しません。NetlifyのサイトIDはRecovery専用です。GitHubの `main` へソースを保存し、Netlify CLIから次のコマンドで配信します。GitHubへのpushだけで更新される自動連携は設定していません。

```sh
netlify deploy --prod --dir dist --no-build --site 1b319774-af76-4e62-9e26-f25ccc0e7a6f
```

`preview/` の確認用スクリーンショットはローカルに保存し、Gitの管理対象から除外しています。
