# Dr.core Recovery LP

TRXなどの器具を使った自重ストレッチを紹介する、Dr.core RecoveryのLPです。承認済みのデザインを共通テンプレートからトップ・月島店・本八幡店の3ページへ展開しています。通常プランは1回30分、初回体験は60分・体組成／姿勢診断付き・1,000円です。既存の大人向けLPのロゴ・写真を使用し、ReViNaとDr.stretchを参考に、白を基調としたわかりやすい構成にしています。ブランドカラーのグリーンとレモンイエローを活かし、ゴールドは主に体験予約の導線に使用しています。

- リポジトリ：[kijimakakeru32-netizen/drcore-recovery-lp](https://github.com/kijimakakeru32-netizen/drcore-recovery-lp)
- 構成の参考：[ReViNaストレッチ青葉台](https://revina-personalgym.com/revina-stretch/aobadai/)
- デザインの参考：[Dr.stretch](https://doctorstretch.com/)
- キャンペーンCTAの参考：[既存Dr.core月島店LP](https://drcore-u18-lp.netlify.app/gyms/tsukishima/)
- 体験の流れ・FAQの確認元：[Dr.core公式サービスサイト](https://drcore.jp/)
- トレーナーの写真・氏名の確認元：[Dr.core採用サイト「それぞれの想い」](https://drcore-recruit-site.netlify.app/#team)
- 制作対象：トップ `/`・月島店 `/gyms/tsukishima/`・本八幡店 `/gyms/motoyawata/` と、共通のお客様の声の記事下書き `/voices/a/`・`/voices/d/`・`/voices/c/`

公開先は次の3ページです。

- [Recoveryトップ](https://drcore-recovery-lp.netlify.app/)
- [月島店](https://drcore-recovery-lp.netlify.app/gyms/tsukishima/)
- [本八幡店](https://drcore-recovery-lp.netlify.app/gyms/motoyawata/)

トップの5つのゴールドCTAは店舗選択 `#locations` へ移動します。店舗LPの5つのCTAは、それぞれの既存の大人向け体験予約URLを別タブで開きます。これは今回のユーザーの明示指示に合わせた導線です。予約URLと店舗名・住所・駅徒歩・写真の対応は `data/recovery-stores.json` にまとめ、既存 `build.py` の店舗データと照合しています。予約リンクには `target="_blank"` と `rel="noopener"` を設定しています。

ファーストビュー直下・初回体験の概要の末尾・料金の後・ページ末尾に、共通の四角い2段構成のゴールドCTAを配置しています。上段の価格枠には「初回60分」「10/31まで」「1,000円」、下段の予約ボタンには「初回体験予約」を表示し、ボタンの外側に「体組成・姿勢診断付き」の説明を添えています。画面下の追従CTAも同じ共通部品で、同じ情報を掲載します。体験の時間・診断内容・価格・キャンペーン期日・ボタン文言は `data/recovery-offer.json` から読み込み、`recovery_sections.py` で生成します。期日は2026年10月31日固定で、毎月の自動延長は行いません。初回体験60分・体組成／姿勢診断付きはユーザー指定に合わせた条件で、通常プランの1回30分とは分けて表示しています。追従CTAはファーストビューを通過すると表示されます。

3つのLPのヘッダーは初期表示では隠し、120px以上スクロールすると中央ロゴとメニューボタンを固定表示します。ページ上部に戻ると再び隠れます。ヘッダー用の空白は設けません。スマートフォンでは写真の高さを基準にコピーを配置し、縦長画面でも写真とメインメッセージの間に大きな余白ができないよう、ファーストビューを内容に合わせた高さにしています。

## ページ構成

1. メインビジュアル・初回体験1,000円
2. 疲労・肩／首・腰・猫背・反り腰・歩行の6つのお悩み
3. Dr.coreのメッセージ「カラダの緊張をほどき、軽やかに動けるように導きます」
4. 写真を使った3つの強み・通常トレーニングへの短い案内
5. 「まずは一度、カラダの変化を感じてみませんか？」：状態確認・ストレッチ・通い方の簡潔な概要と体験予約バナー
6. お客様の声の3カード
7. Dr.coreのトレーナー紹介の4カード
8. 利用時間別の月額料金表2種類・入会金と当日入会特典の独立カード・体験予約バナー
9. 5ステップの体験の流れ
10. 7問のFAQ
11. 月島店・本八幡店の紹介
12. ページ末尾の初回体験の案内

店舗LPは同じ構成を保ち、ファーストビューに店舗名と駅徒歩を表示します。FAQと店舗一覧の間には、それぞれの店舗写真・住所・アクセスをまとめた `#access` を追加しています。店舗カードとフッターからトップ・各店舗へ移動でき、同じ店舗のカードはそのページのアクセス案内へ移動します。

メインコピーは「自重ストレッチで、しなやかに動ける身体へ。」、補足は「筋肉から脳まで、トレーナーがマンツーマンで整えます」です。スマートフォンでは写真を背景に配置し、引きの構図と薄いグラデーションを使って人物・ストレッチ動作を見やすくしています。特徴は3つの円を横並びにし、「完全予約制」「マンツーマン」の間の「／」は削除しています。高さは画面サイズへの固定ではなく、写真とコピーの内容に合わせ、可読性を優先しています。

お悩みは一段濃いグレー背景の6つのカードで、ラベルと説明文を整理しています。人物イラストはLPから除去しています。スマートフォンの見出しは「最近、このような」「体の変化はありませんか？」の2行です。明るい背景のメッセージを挟み、解決への転換をつくっています。

「お客様の目的例」は削除し、お客様の声の次にトレーナー紹介を配置しています。フッターは黒背景にしています。

強みは「プロが導く、最適なストレッチ」「多彩な器具で、全身を深く伸ばす」「伸ばすだけじゃない。動きやすい身体へ。」の3点です。見出しは「Dr.core 自重ストレッチ」「3つの強み」の2行で「｜」を使わず、既存の説明文を維持しています。

初回体験の概要は「まずは一度、カラダの変化を感じてみませんか？」と「あなたに合ったストレッチを、初回体験で。」を配置しています。3項目は「今のカラダを一緒にチェック」「カラダに合わせて、無理なく伸ばす」「目標と生活に合う通い方をご案内」です。それぞれ、気になる悩みと姿勢・動かしやすさの確認、トレーナーのサポートによるストレッチ、目標と通える頻度に合うプランの提案を説明します。

初回体験の概要と後半の詳しい体験の流れは役割を分けています。後半は「体験予約 → ご来店 → 身体の状態確認 → ストレッチ体験 → 続け方をご案内」の5ステップで、各項目に番号・画像・タイトル・補足説明を配置します。スマートフォンは縦に読み進める構成です。FAQは身体の硬さ・体験・ストレッチ専門プラン・通う頻度・時間別料金・入会の任意性・予約先の7問を、キーボード操作できる `details` / `summary` で実装しています。

体験の流れとFAQは、採用サイトではなくDr.core公式サービスサイトの構成と確認できた案内を基にストレッチ向けへ調整しています。初回体験60分・体組成／姿勢診断付き・1,000円は、今回のユーザー指定を反映しています。Recoveryでの適用が確認できない持ち物・着替え・支払い方法は追加していません。

競合の口コミや効果保証は転載していません。既存大人向けLPの先着人数、キャンペーン期限、月会費の永続割引、ペア割引はRecoveryに適用していません。

## お客様の声の下書き

3つのLPのカードと共通の個別記事は `data/voices.json` から生成します。掲載順はAさん・Dさん・Cさんで、写真枠を含むカード全体のクリックから `/voices/a/`・`/voices/d/`・`/voices/c/` に移動できます。LPカードは写真枠、名前と年代、紹介タイトル、紹介文を掲載し、属性・テーマ・主な悩み・サンプル表示・「詳しく読む」の文言を除いています。カードは小さめの横スクロール形式で、スワイプ・トラックパッド・左右ボタンに対応します。見出しは短く整理した2行で、`card_title` の改行位置をそのまま表示します。紹介文と詳細記事の原稿は維持しています。各記事の一覧へ戻るリンクは、共通トップの `/#voices` へ移動します。

現在は3件とも `is_sample: true` の掲載イメージで、実際の取材は行っていません。指定に合わせ、LP上のサンプル表示を削除し、個別記事のサンプル表示は維持しています。個別記事の属性・テーマ・主な悩み・本文は変更していません。記事タイトルには各原稿の冒頭の引用文を使用しています。写真は未提供のため、LPカードと記事には中立的な「お客様写真 掲載予定」のプレースホルダーを表示します。`data/voices.json` の任意項目 `photo` にローカル画像のパスを設定すると、対応するカードと記事の写真枠へ反映されます。画像の説明は `photo_alt`、表示位置は `photo_object_position` で指定できます。

記事の本文は `paragraphs` に原文を段落ごとに保存しています。Aさんは7段落、Dさんは9段落、Cさんは10段落です。生成処理は各段落を省略・要約・切り詰めず、段落内の改行も保持して全文を表示します。下書き記事には `noindex,follow` を設定し、サイトマップには含めていません。実際のお客様の声として掲載する際には、原稿・写真とサンプル表記を確認します。

## 料金の表示

金額・回数・入会金・他時間帯の加算額は `data/recovery-plans.json` で管理し、`recovery_sections.py` が2つの料金表を生成します。各プランの指定金額は1回あたりの料金で、月額は回数分を計算します。

税区分はRecoveryとして未確認のため、`tax_label` は `null` のままです。既存成人サービスの税込表記をRecoveryにも適用できるとは判断せず、税込・税別の表記を加えていません。

プラン1：平日10:00〜15:00でご利用の場合。既存の金額を維持し、月2プランの「10,500円〜」「5,250円〜」から料金表内の「〜」だけを削除しています。

| プラン | 1回あたり | 月額 |
| --- | ---: | ---: |
| 月1プラン（月1回） | 6,000円 | 6,000円 |
| 月2プラン（月2回） | 5,250円 | 10,500円 |
| 月4プラン（月4回） | 5,000円 | 20,000円 |
| 月8プラン（月8回） | 4,750円 | 38,000円 |

プラン2：平日（上記以外）＆土日祝でご利用の場合。1回あたりに1,000円を加え、月額には「回数 × 1,000円」を加算します。

| プラン | 1回あたり | 月額 |
| --- | ---: | ---: |
| 月1プラン（月1回） | 7,000円 | 7,000円 |
| 月2プラン（月2回） | 6,250円 | 12,500円 |
| 月4プラン（月4回） | 6,000円 | 24,000円 |
| 月8プラン（月8回） | 5,750円 | 46,000円 |

料金導入の「パーソナルだけど4,750円〜/回」は維持し、「1回30分だから、気軽に通えて継続しやすい」を大きく表示しています。料金表の囲み枠をなくし、プラン1を先に、プラン2を濃い緑で表示しています。入会金33,000円は導入見出しから分けた独立欄に掲載し、その下に「今なら／体験当日のご入会で／入会金0円」のゴールドバナーを配置しています。通常プランは1回30分。初回体験は60分・体組成／姿勢診断付き・1,000円です。

## トレーナーの素材

採用サイト「それぞれの想い」の公開HTMLで、氏名・写真・トレーナー表記を確認した高倉・吉岡・吉永・久保木の4名を掲載しています。紹介カードは写真と「名字＋トレーナー」のみで、経歴・資格・担当店舗を推測していません。

`data/trainers.json` に人物と写真の対応、画像サイズ、トリミング位置、取得元URL、SHA-256を記録しています。画像原データは `dist/assets/trainers/` に保存し、外部画像への直接参照に依存しません。詳しい確認記録は `data/trainers-sources.md` を参照してください。木嶋氏は別セクションの代表として掲載されており、今回の4名には含めていません。

- `templates/recovery-home.html`：トップページの構成・本文・共通部品の配置
- `templates/partials/recovery-flow.html`：5ステップの体験の流れ

- `data/recovery-plans.json`：回数・単価・時間帯別の加算額・入会金・税区分
- `data/recovery-stores.json`：店舗名・住所・アクセス・写真・承認済み予約URL
- `data/trainers.json`：トレーナーの表示名・写真・トリミング・出典
- `data/trainers-sources.md`：トレーナーの写真と氏名の確認記録
- `data/voices.json`：お客様の声の属性・サンプル指定・任意の写真と表示位置・カードの紹介文・記事の全文原稿
- `templates/recovery-voice.html`：お客様の声の個別記事テンプレート
- `dist/assets/recovery.css`：Recoveryのデザイン・レスポンシブ表示
- `dist/assets/recovery-stores.css`：店舗LPの店舗名・アクセス情報・店舗リンクの表示
- `dist/assets/voices.css`：お客様の声カード・個別記事・写真プレースホルダーのデザイン
- `dist/assets/recovery.js`：モバイルメニュー・追従CTA・体験案内クリックの記録
- `dist/assets/logo-dark.svg`：白背景用のDr.coreロゴ
- `dist/assets/concerns/`：LPでは使用していない既存のお悩みイラスト素材
- `dist/assets/flow/`：体験の流れに使うイラスト
- `dist/assets/trainers/`：取得元を確認したトレーナー写真
- `recovery.py`：3つのLPとお客様の声の記事生成・アセットのキャッシュ更新・公開URL情報
- `build.py`：ビルドの入口。通常はRecoveryトップ・2店舗・3記事を一括生成
- `verify.py`：3つのLP・共通記事・予約URL・店舗情報・相対リンク・公開メタ情報の静的検証

プロジェクトのルートで実行します。Python標準ライブラリを使用するため、ビルド用の追加パッケージは不要です。

```sh
python3 build.py
python3 verify.py
node --check dist/assets/recovery.js
```

既存の `python3 build.py --full` もRecoveryのトップ・2店舗・3記事を生成します。生成済みの `dist/index.html`・`dist/gyms/*/index.html`・`dist/voices/*/index.html` は直接編集せず、テンプレート・店舗データ・原稿データを編集して再ビルドしてください。

公開用のビルドとメタ情報の確認は、確定した公開URLを指定します。

```sh
python3 build.py --origin https://drcore-recovery-lp.netlify.app
python3 verify.py --origin https://drcore-recovery-lp.netlify.app
```

3つのLPにそれぞれのcanonical・OG情報を設定し、サイトマップにはトップ・月島店・本八幡店の3URLのみを掲載します。下書きのお客様の声の記事は `noindex,follow` を維持し、サイトマップから除外します。`robots.txt` は `/gyms/` を含むLPのクロールを許可します。`--origin` を指定しないローカル用ビルドではcanonicalを付けず、サイトマップは空になります。

## 店舗ページと継続する確認事項

引き継いだ `dist/gyms/tsukishima/` と `dist/gyms/motoyawata/` はRecoveryの店舗LPへ更新しています。通常ビルドでトップと同時に生成し、各ページからほかの店舗とトップへ移動できます。成人LPを再生成する保守用オプションは `--legacy-adult` です。`--legacy-adult --full` は同じトップと店舗URLを成人ページで上書きするため、Recoveryの編集・公開には使用しません。

今回の店舗展開で条件を推測して追加せず、次の項目は継続して確認します。

- 税区分と実際の請求額
- 各店舗での受付可能な日時と、60分の初回体験の運用
- Recoveryに適用する持ち物・着替え・支払い方法などの案内
- 将来Recovery専用の予約URLへ切り替える場合の各店舗のURLと運用
- お客様の声のサンプル原稿の掲載方針と掲載写真

`netlify.toml` はNetlify用のビルド・配信設定です。公開用ビルドで設定された `$URL` をoriginとして使用し、3つのLPと共通記事を生成・検証します。

本番公開は、上記の公開用ビルド・検証のあとに次のコマンドで行います。NetlifyのサイトIDはRecovery専用です。今回の公開ではGitHubの`main`へソースを保存し、Netlify CLIから配信しています。GitHubへのpushだけで更新される自動連携は設定していません。

```sh
netlify deploy --prod --dir dist --no-build --site 1b319774-af76-4e62-9e26-f25ccc0e7a6f
```

`preview/` の確認用スクリーンショットはローカルに保存し、Gitの管理対象から除外しています。
