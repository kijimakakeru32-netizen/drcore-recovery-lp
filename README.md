# Dr.core 自重ストレッチ LP

器具に身体を支えてもらいながら行う「自重ストレッチ」を紹介する、Dr.coreのLPです。平日昼の予約につながるよう、ラクに伸ばせることと日常のすき間に通えることを伝え、トップ・月島店・本八幡店の3ページを共通テンプレートから生成しています。通常プランは1回30分、初回体験は60分・体組成／姿勢診断付き・1,000円です。既存の大人向けLPのロゴ・写真を使用し、ReViNaとDr.stretchを参考に、白を基調としたわかりやすい構成にしています。ブランドカラーのグリーンとレモンイエローを活かし、ゴールドは主に体験予約の導線に使用しています。

都度払いの価格は、ユーザー指定により平日デイタイム7,000円・レギュラー8,000円で確定しています。体験時のレンタルウェア・汗ふきシート・ウォーターサーバーはすべて無料で、手ぶらで来店できることがユーザー指示により確定しています。普段着の可否、着替えスペース、シャワーの案内は掲載していません。

## お客様の声の下書き

3つのLPのカードと共通の個別記事は `data/voices.json` から生成します。掲載順はAさん・Dさん・Cさんで、写真枠を含むカード全体のクリックから `/voices/a/`・`/voices/d/`・`/voices/c/` に移動できます。LPカードは写真枠、名前と年代、紹介タイトル、紹介文を掲載し、属性・テーマ・主な悩み・「詳しく読む」の文言を除いています。カードは小さめの横スクロール形式で、スワイプ・トラックパッド・左右ボタンに対応します。見出しは短く整理した2行で、`card_title` の改行位置をそのまま表示します。各記事の一覧へ戻るリンクは、共通トップの `/#voices` へ移動します。LPと3つの個別記事に「※個人の感想です。感じ方や変化には個人差があります。」を掲載しています。

原稿は3件とも `is_sample: true` の確認用サンプルで、実際の取材内容としては未確定です。Aさんは平日昼の利用シーンに合わせたカード・記事タイトルと本文を維持しています。Aさんの写真はユーザー提供の `assets/voices/customer-a.png` を3つのLPカードと詳細記事に掲載し、`editorial_label` を `null` として「平日昼の利用イメージ（取材・写真確認待ち）」と写真待ちの表示を削除しています。Dさんにもユーザー提供の `assets/voices/customer-d.png` を同じく3つのLPカードと詳細記事に掲載しています。Cさんにもユーザー提供の `assets/voices/customer-c.png` を3つのLPカードと詳細記事に掲載し、3名とも写真用プレースホルダーと写真待ちの案内を表示しません。Dさん・Cさんの原稿は変更していません。3件の個別記事では公開画面のサンプル注記を削除し、内部の `is_sample: true` と `noindex,follow` は維持しています。`data/voices.json` の任意項目 `photo` にローカル画像のパスを設定すると、対応するカードと記事の写真枠へ反映されます。画像の説明は `photo_alt`、表示位置は `photo_object_position` で指定できます。

記事の本文は `paragraphs` に段落ごとに保存しています。Aさんは8段落、Dさんは9段落、Cさんは10段落です。生成処理は各段落を省略・要約・切り詰めず、段落内の改行も保持して全文を表示します。下書き記事には `noindex,follow` を設定し、サイトマップには含めていません。実際のお客様の声として掲載する際には、原稿・写真とサンプル表記を確認します。

## 料金の表示

金額・回数・入会金・レギュラープランの加算額・都度払い価格は `data/recovery-plans.json` で管理し、`recovery_sections.py` が2つの料金表を生成します。都度払いは各料金表の先頭行で案内し、続けて月額4プランを掲載します。月額プランの指定金額は1回あたりの料金で、月額は回数分を計算します。

税区分は自重ストレッチとして未確認のため、`tax_label` は `null` のままです。既存成人サービスの税込表記を今回の自重ストレッチにも適用できるとは判断せず、税込・税別の表記を加えていません。

入会金の独立ブロックはLPに掲載しません。`data/recovery-plans.json` の `enrollment_fee: 0` はデータ上の条件として保持しています。1回30分の都度払いは、`pay_as_you_go.daytime_price` が7,000円、`regular_price` が8,000円です。各料金表の先頭行だけで案内し、月額欄は「-」とします。金額は共通データを参照し、プランごとの一致を検証します。通常プランの30分と、体組成・姿勢診断を含む初回体験60分・1,000円は別に案内しています。

## トレーナーの素材

採用サイト「それぞれの想い」の公開HTMLで、氏名・写真・トレーナー表記を確認した高倉・吉岡・吉永・久保木の4名を掲載しています。紹介カードは写真と「名字＋トレーナー」のみで、経歴・資格・担当店舗を推測していません。

`data/trainers.json` に人物と写真の対応、画像サイズ、トリミング位置、取得元URL、SHA-256を記録しています。画像原データは `dist/assets/trainers/` に保存し、外部画像への直接参照に依存しません。詳しい確認記録は `data/trainers-sources.md` を参照してください。木嶋氏は別セクションの代表として掲載されており、今回の4名には含めていません。

## 計測

既存の公開済みGTMコンテナ `GTM-TJ8DFDN6` を利用します。トップ・2店舗・お客様の声3記事の計6ページに、charsetメタ直後の標準ローダーとbody開始直後の非表示noscript iframeを共通partialから1回ずつ展開し、通常ビルド後も維持します。`verify.py` は設置位置・ID・重複を確認します。

予約導線の既存 `recovery_trial_interest` イベント（`program`・`position`・`destination`）は引き続き `dataLayer` へ送ります。Clarityの直接埋め込みは追加していません。

プロジェクトのルートで実行します。Python標準ライブラリを使用するため、ビルド用の追加パッケージは不要です。現在の都度払い価格は確定しており、通常のローカル確認も公開時も `--allow-pending-content` を付けずに検証します。

```sh
python3 build.py --origin https://drcore-recovery-lp.netlify.app
python3 verify.py --origin https://drcore-recovery-lp.netlify.app
node --check dist/assets/recovery.js
```

既存の `python3 build.py --full` もDr.coreのトップ・2店舗・3記事を生成します。生成済みの `dist/index.html`・`dist/gyms/*/index.html`・`dist/voices/*/index.html` は直接編集せず、テンプレート・店舗データ・原稿データを編集して再ビルドしてください。

公開用のビルドとメタ情報の確認は、確定した公開URLを指定し、`--allow-pending-content` を付けずに実行します。各料金表の先頭行にある都度払いの確定金額7,000円・8,000円、および従来の月額料金を検証します。内部確認用の `data-pending-content` が残っている場合は、引き続き公開用検証で拒否します。

```sh
python3 build.py --origin https://drcore-recovery-lp.netlify.app
python3 verify.py --origin https://drcore-recovery-lp.netlify.app
```

3つのLPにそれぞれのcanonical・OG情報を設定し、サイトマップにはトップ・月島店・本八幡店の3URLのみを掲載します。下書きのお客様の声の記事は `noindex,follow` を維持し、サイトマップから除外します。`robots.txt` は `/gyms/` を含むLPのクロールを許可します。`--origin` を指定しないローカル用ビルドではcanonicalを付けず、サイトマップは空になります。

## 店舗ページと継続する確認事項

引き継いだ `dist/gyms/tsukishima/` と `dist/gyms/motoyawata/` はDr.coreの自重ストレッチ店舗LPへ更新しています。通常ビルドでトップと同時に生成し、各ページからほかの店舗とトップへ移動できます。成人LPを再生成する保守用オプションは `--legacy-adult` です。`--legacy-adult --full` は同じトップと店舗URLを成人ページで上書きするため、このLPの編集・公開には使用しません。

条件を推測して追加せず、次の項目を確認します。

- 普段着での利用可否、各店舗の着替えスペース・シャワーの有無（公開画面では未掲載）
- 税区分と実際の請求額
- 各店舗での受付可能な日時と、60分の初回体験の運用
- 自重ストレッチの支払い方法などの案内
- お客様の声のサンプル原稿の掲載方針と掲載写真

`netlify.toml` はNetlify用のビルド・配信設定です。公開用ビルドで設定された `$URL` をoriginとして使用し、3つのLPと共通記事を生成・検証します。

本番公開は、内部確認用の文言・属性を外し、未確定条件を断定しない問い合わせ案内に整えたうえで、フラグなしの公開用検証に合格してから行います。確認用フラグで検証した成果物をそのまま公開しません。NetlifyのサイトIDはこの自重ストレッチLP専用です。GitHubの `main` へソースを保存し、Netlify CLIから次のコマンドで配信します。GitHubへのpushだけで更新される自動連携は設定していません。

```sh
netlify deploy --prod --dir dist --no-build --site 1b319774-af76-4e62-9e26-f25ccc0e7a6f
```

`preview/` の確認用スクリーンショットはローカルに保存し、Gitの管理対象から除外しています。
